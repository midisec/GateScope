# 结构识别 V2：精确绘图、候选留档与完成概率

2026-09-10 · 当前模型 `structure-study-2.1` · 迁移 `0023_structure_lifecycle`、`0024_structure_rule_revision`。本文件替代 [V1 文档](18_CHART_PATTERNS_AND_WAVES.md) 中的当前识别、确认与保存口径；旧报告和既有策略/交易证据保留，不混入新版本的完成概率。本次不启用实盘或改变已有告警策略。

## 页面入口

`/markets/chart` → 主图下「形态与波浪」。

- 当前结构：点选原理线；形成中/已形成卡片列出同币种、同周期、同阶段、同初始评分分组的历史确认率、样本数与校正区间。最近失效/到期也可选择；完整记录在档案中。
- 历史表现：点击计算/更新，最多 8,000 根逐根回放。上表是候选最终确认表现，计入失效、到期；下表是方向收益，不能把两者当成同一种胜率。支持阶段、评分组、形态筛选与分页。
- 候选档案：持续观测 / 历史回放、状态、形态筛选，每页 12 条。历史回放支持选旧批次（下拉最多最近 100 批，所有已知批次/候选仍可按 ID 查询）。弹窗默认显示首次识别的结构；时间线可查看后来的形成、失效、到期或确认节点。

## 识别与几何

固定 480 根窗口、左右各 4 根确认枢轴，只有已收盘 K 线进入识别。几何评分阈值 0.55 是规则参数，不是经过标注样本验证的识别准确率。

`pattern_engine.py` 的 `precision_mode` 与 `latest_only` 为显式开关，默认关闭，旧回测/告警的黄金测试语义不变。V2 单独启用：

- 双顶底：两极点差不超过 0.75 个局部 ATR、深度不少于 1.5 ATR；三顶底离散度不超过 1 ATR。头肩形态用 ATR 校验头部突出及肩部误差。
- 通道/三角形等边界的斜率阈值按 ATR 和结构跨度归一化；边界不得交叉、宽度需达阈值，枢轴至边界的均方根残差不超过 0.8 ATR。其形状评分独立于突破结果。
- 旗形旗杆至少 3 ATR，杯柄深度至少 3 ATR；杯口锚点从真实收盘价选取，取消“平均价格放到任意蜡烛上”的偏移。其余持续时间、回撤比例和 ABC 比例仍是模型选择，不宣称穷举所有形态。
- 推动浪保留标准子集硬约束：2 不越过起点、4 不重叠 1、3 不能最短。缺失浪不制造目标价格或未来时间。形成中前缀目前覆盖双顶/双底和 6 类波浪，其他完整形态首次以「已形成」入档；不是全部 26 类都支持未完成前缀。
- 2.1 修正 ABC 前缀与完整结构门槛不一致：A 浪幅度统一要求至少 A 枢轴处的 1.5 ATR，取消完整 ABC 的固定 2.5% 门槛，评分同样改为 ATR 单位，C 终点容差采用 0.25 ATR。保留 2.0 完整报告/档案，重新回放 2.1；旧模型尚未完成的持续观测候选以 MODEL_CHANGED → CENSORED 中断，不计成败，不复用其估计。

每个拐点保存时间、原价和 HIGH/LOW/CLOSE 来源。图上的圆点中心通过图表原生时间/价格坐标换算；标签可避让，圆点不位移。颈线、边界按每个真实蜡烛时间采样其算术价格，避免对数轴仅连接两个端点导致中间价偏差。已知腿用实线，暂定腿和参考线用虚线，失效参考用红点线。失效参考基线与实际收盘触发缓冲在规则中区分。任何必要点缺失则不画残缺图，不吸附到邻近蜡烛。

标准规则来源：[Elliott Wave International：Impulse](https://www.elliottwave.com/waveopedia/impulse/)。本实现中的 ATR、比例、期限和评分权重是可版本化的模型假设，不是数学盈利证明。

## 不可删改的候选生命周期

| 节点 | 条件 | 是否进入完成率分母 |
| --- | --- | --- |
| 形成中 FORMING | 已有部分确认枢轴，后续结构未完成 | 否，继续观察 |
| 已形成 FORMED | 完整几何满足模型规则 | 否，继续观察 |
| 已确认 CONFIRMED | 入档/形成之后，连续两根收盘越过确认线及固定 0.15 ATR 缓冲 | 是，成功 |
| 已失效 INVALIDATED | 预先固定的结构失效边界被突破 | 是，失败 |
| 到期 EXPIRED | 达到期限或收敛边界已相交而未确认 | 是，失败 |
| 中断 CENSORED | 观测 K 线不连续，不能可靠判定 | 否，单独计数 |

模型发生不兼容规则修订也进入 CENSORED，并标注模型变更原因。旧模型的持续观测档案可通过「模型档案」下拉回看，历史报告批次也保留。

失效先于确认判定；常规用收盘加缓冲，标准推动浪硬失效条件用极值。确认不回填到历史枢轴，最早在完整结构入档之后的第二根收盘确认。原模型在识别前已发生的突破，不直接当成当前确认。

图表形态期限 48 根、波浪 96 根、完整周期 144 根，从首次候选开始，不因进展重置。推动五浪完成后研究反向修正，末段 23.6% 为确认参考，不把第五浪顶当买点。ABC/周期完成研究末段后的反转；中性箱体/对称三角形等到实际确认方向才确定收益方向。

候选 ID 使用模型、类型与稳定的原始锚点：双顶底前两点、推动/ABC 前三点、完整周期前六点；边界类最早三锚点，其余完整几何。后续扫描不再返回某候选**不是**失败，也不删除。已终结的 ID 不复活。新增已确认枢轴仅生成显式 PROGRESS/FORMED 节点，保留 `first` 初始条件、期限和全部先前快照。

`market_pattern_events` 为追加式事实，数据库触发器拒绝 UPDATE/DELETE；API 只有 SELECT，worker 只有 SELECT/INSERT。`market_pattern_reports` 归档每个完成批次，升级前的旧报告也归档。热缓存清理和新一轮回放不删除任何事实。

## 数学口径与置信边界

按同币种、周期、模型、类型、首次阶段和初始评分组计数。评分组为未评分、55–69、70–84、85–100；表格另有 ALL 汇总。相同类型/阶段使用首次观察顺序的非重叠观察期取样，不按成败挑样本。

`N = 已确认 + 已失效 + 已到期`（仅非重叠已结束样本）

`历史最终确认率 = 已确认 / N`

待定、中断、重叠排除单独展示。总数中的阶段是互斥最终状态；「曾形成」可与「已确认」重叠，不能相加。形成中组关注最终确认，而非仅第二枢轴出现；它不是盈利概率。

当前卡片的参考只用 `resolved_time < 当前观测收盘时间` 的样本，且排除当前候选 ID；不混入其他币种/周期、不将旧模型强行换算。当前参考可随着新的已结束样本更新，不冒充首次识别时的预测。历史回放每个阶段另冻结当时可用的估计，训练结果推迟到下一根 K 线，防止同根训练泄漏；Brier = mean((p−y)²) 只取当时已满足样本门槛的非重叠前向预测。持续观测的首次前向估计从其自身已观测历史训练，可能比卡片历史回放参考的样本少。

Wilson 区间，`z = Φ⁻¹(1−0.05/(2×260))`，260 = 26 类型 × 2 首次阶段 × 5 分组。至少 20 个有效样本才显示区间；没有数据是 `—`，不是 0%。这仅是在相应独立性假设下的同一报告多重比较校正，不保证市场非平稳/时间相关条件下的真实覆盖率，不覆盖重复看盘、反复刷新和规则调优产生的全部选择偏差。公式参考 [NIST：二项比例置信区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)。

方向净收益仍按下一根开盘入场、后续 5/10/20/50 根末收盘、双边合计 0.10% 假设成本计算，使用独立的 208 组区间口径。已确认形态后续仍可能亏损。没有人工标注的独立测试集/滚动样本外验证，不能声称本轮识别准确率提升了某个百分比，也不能保证获利。

## 服务与资源控制

- GET `/api/v2/patterns/current` 读取已持久化的追踪投影，同时续约公共行情缓存跟踪，不再在每次 API 请求中返回未留档的临时候选。30 秒缓存、16 组 LRU、返回最近最多 96 个结构。
- GET `/api/v2/patterns/events` 支持来源、状态、类型、批次以及 limit/offset；GET `/api/v2/patterns/events/{context}/{candidate}` 返回原始和后续节点及图。均需登录，不包含用户凭据、订单或私人策略。
- 后台沿用 `gatescope-strategy`，跟踪所有活跃自选周期；非自选图表最多 64 个近期请求租约。未到期候选即使用户离开页面也跟踪到终结。首次启用从当前已收盘节点开始，过去数据只能标为 REPLAY，不能冒充当时已记录。
- 每次实时切片目标 1 秒、最多 16 根；历史切片目标 2 秒、最多 64 根。定期让出给原告警/回测任务。单次计算及原有回测仍可能超出此软预算，不承诺交易级实时 SLA。
- 热状态只保留活跃候选及最近 480 根内终结投影，全部历史留在不可变表中。全量研究最多 16,000 个候选、同时最多 512 个活跃候选，过密时显示错误而非静默丢弃。
- 行情保留实际版本：原始图区按首次识别时的 `snapshot_at` 重建当时版本，截止首次观测收盘；之后才接后续行情。历史回放以收盘可知为假设，事件同时显示真实落库时间。实时漏过的缺口导致 CENSORED，不越过缺口继续拟合。
- 不新增常驻进程；测试、浏览器、构建串行。上线前备份、增量迁移，再重启 API/strategy 并原子发布静态资源；保留旧哈希文件供已打开页面加载。
