# 现有 Web 模块功能验收

范围：正式系统已展示的功能，不以隐藏错误、绕过 MFA/交易资格或虚构结果来制造“可用”。本轮不创建真实订单、不主动发送生产通知、不改写历史报告。

## 验收清单

| 模块 | 必测操作 | 状态 |
| --- | --- | --- |
| 登录/会话 | 会话读取失败重试；认证、MFA 与恢复码 | 浏览器重试通过；认证生命周期由 PostgreSQL 集成测试覆盖 |
| 行情/自选 | 搜索、切换周期、保存并恢复布局、弹窗键盘 | 桌面/手机通过；自选持久化和多周期采集由集成测试覆盖 |
| 概率告警 | 创建失败重试与重载、暂停/恢复、列表翻页、可搜索币种 | 桌面/手机通过；恢复的 ETag、权限、不可变版本通过数据库/API 测试 |
| 回测 | 默认报告、队列、失败、历史分页、图表、逐笔记录、重试 | 两套浏览器回归通过；队列/结果/隔离通过集成测试 |
| PAPER | 新增/选择账户、ABSTAIN 提示、取消确认、交易详情、分页、权限 | 浏览器通过；批准与账本生命周期由集成测试覆盖 |
| 交易所/TESTNET | 加密凭据提交、轮换/停用弹窗、错误重试、执行资格提示 | 浏览器请求桩通过；凭据准入/TESTNET 门禁通过集成测试 |
| Telegram | 绑定链接/本地二维码、连续两次通道测试、路由新增/编辑、列表分页 | 桌面/手机通过；真实 Telegram 投递不在本轮测试范围 |
| MCP | 客户端新增、签发、一次性令牌防误关、分页、权限提示 | 浏览器通过；令牌认证/吊销由集成测试覆盖 |
| 数据源 | 加密保存、检测反馈、刷新回看、失败重试 | 浏览器与数据库当前密钥版本结果回读通过 |
| 用户设置 | 会话分页、退出其他设备确认、失败重试、保留最后一个验证器 | 浏览器通过；验证器生命周期由认证集成测试覆盖 |
| 消息中心 | 服务端分页、状态筛选、详情弹窗、刷新/重试、用户隔离 | 浏览器、数据库与 API 测试通过 |

每个模块需在 1440px 桌面与 390px 手机视口检查。浏览器交互测试拦截外部写请求；真实 PostgreSQL 集成测试仅使用独立 gatescope_test 数据库。生产检查限于服务健康与已有数据读取。

## 发现与修复记录

完成日期：2026-09-09（Asia/Shanghai）。本轮不是实盘或第三方生产联调验收。

1. 共用 `ui.tsx` / `ui.css`：原生模态框、焦点恢复、Esc/遮罩关闭、忙碌时阻止误关、危险操作确认、统一分页和错误重试。业务异常不再只表现为空列表；HTTP 超时/非 JSON/断网具有明确反馈，写操作不自动重试。
2. 回测历史、消息列表增加服务端 `limit/offset/total/has_more/next_offset`；消息未处理数按当前用户的所有投递记录统计，不再只数当前页。排序采用创建时间与 ID，避免状态更新改变顺序。
3. 告警可暂停后恢复；恢复使用 If-Match，检查当前状态、标的可用性、用户权限，不创建新历史版本。币种保留自选优先、输入搜索的选择器。
4. PAPER 可继续新增多个模拟账户，并明确选择提案使用的账户。账户、提案、账本分页；交易详情弹窗加载时清空旧内容，取消旧请求，避免串单。原始证据 K 线优先于同时间后续数据，图中显示冻结入场/TP/SL 价位。
5. Telegram 不再依赖异步请求完成后的 `window.open`，改为可点击链接及浏览器本地二维码；测试反馈持续保留，按钮恢复为“发送测试”。路由支持弹窗新增/编辑/删除，免打扰不再默认开启，既有过滤和风险绕过规则保留。
6. Coinglass 配置读取同时返回当前凭据版本的最近脱敏检测记录。刷新/重访不再丢失结果；保存与重新检测互斥，敏感表单清理，离开页面停止继续轮询。
7. MCP 管理独立成模块；一次性令牌需确认保存后才能关闭，吊销确认、客户端/令牌分页、提交互斥。OWNER 管理权限未扩张；普通成员直接访问管理路径时有明确无权限页面。
8. 登录页工作区读取失败可重试；会话服务失败不会卡在无限加载；会话过期返回登录。图表工作台恢复所存标的、周期和指标模板，保存具有进度反馈。

## 保留的明确边界

- 真实 Telegram 收件、Coinglass/LSR 实际权限额度、交易所 API 读写权限，需要凭据持有人按页面操作做生产联调。本轮不会伪称真实消息已送达，也没有真实下单。
- LIVE 仍是服务端硬禁用；TESTNET 仍需有效认证、空闲已解锁账户及 MFA。研究回测/形态告警不能凭 UI 按钮提升执行资格，更不构成盈利保证。
- 告警当前显示最近 100 条；PAPER 信号/提案/交易最近 50 条；TESTNET 账本最近 100 条。这些是最近记录的客户端分页，不冒充全历史服务端分页。全历史服务端分页本轮覆盖消息与研究回测。
- 本轮测试不是所有浏览器/设备或高并发容量认证；未修改其他项目的进程。大样本报表和并行回测仍需单独负载测试。
