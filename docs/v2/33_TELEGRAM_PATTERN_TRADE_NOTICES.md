# Telegram 形态做单观察通知

日期：2026-09-12。用户请求：配置形态形成后、基于该形态的做单通知。

## 配置范围

默认按当前用户的 BTC_USDT、ETH_USDT 自选快照，覆盖 1h、4h、8h、1d，新增8条 `TG形态做单观察` 规则，使用其已绑定的有效 Telegram 通道。原有 `eth看空` 规则保留，不覆盖用户自定义条件。两个独立规则若命中同一形态，仍可能分别通知；可在策略页暂停不需要的规则。

覆盖现有28类形态/波浪；ANY为每个独立确认事件分别通知，不再只挑一个。`confirmed_only=true`，不额外设置几何评分下限，冷却为0，同一规则版本内按原始结构证据幂等去重；不是重复扫描就重复发。新鲜度、收盘确认、失效和15分钟上限仍有效，历史过期信号不补发为当前机会。

这是当前自选的配置快照，不是自动扩展到未来所有新自选的订阅。新增币种或变更周期，可在 `/strategies/alerts` 新建/编辑规则。编辑器和新建表单均有“通知时机”：突破确认后，或已形成预告加突破确认。Telegram绑定/通道在 `/settings/notifications`。

## 通知内容与原始证据

确认时的原始已收盘价格作为参考（不是成交价）；原结构失效规则作为止损参考；仅使用原始 `CONDITIONAL_MOVE` 的条件目标，绝不将形成中下一拐点目标当止盈。价差盈亏比不扣费用，不作为新门槛。几何匹配是分数，不是获利概率；不制造历史胜率。

价格、形态线、目标和证据身份冻结入不可变告警。原始价格按当次结构事件的 `snapshot_at` 查询当时可用的K线修订，不使用后续更正的收盘价。事务 `now()` 可能早于墙钟快照时间，可用时间取观测、记录和快照的最大值，并拒绝本轮时钟之后的快照。

`READY` 仅表示观察计划点位完整；`WAIT_CONFIRMATION` 表示等待确认；`UNAVAILABLE` 表示方向/目标/失效线缺失或不合理。任何状态都不授权下单。部分方向确认前无单侧目标的结构可能缺少原始条件目标，通知明确不可用，不在发送时改造旧预测。结构失效线并不是已经挂到交易所的止损单。

自动推送一条文字消息，附“通知原图 / 做单计划”和“最新形态状态”按钮；图片按需点击返回，不自动双发图片。按钮绑定告警事件UUID，经租户与用户归属校验，不依赖24小时菜单。用户移出自选后仍可查询本人历史事件。

原图精确匹配 context、candidate、evidence、模型版本及RECORDED来源，按事件当时修订绘图，只画形态不附指标副图。最新状态图保留原线和原计划，仅追加连续后续行情；行情有缺口、精确归档缺失或锚点不完整时明确降级，不以别的历史阶段冒充。形态最新状态不是实际持仓止盈止损结果。
