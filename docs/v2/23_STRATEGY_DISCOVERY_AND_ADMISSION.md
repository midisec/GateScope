## 精确阈值与统计口径

| 门禁 | 必须满足 | 口径 |
| --- | --- | --- |
| OOS_SHARPE | 夏普严格 **> 1.5** | 后段完整 UTC 日净值收益，保守 HAC 年化评分 |
| OOS_DRAWDOWN | 最大回撤严格 **< 0.15** | 全区间与独立验证账户逐 K 线盯市回撤的较大值 |
| OOS_HIT_RATE | 命中率严格 **> 0.55** | 后段净盈利交易 / 后段所有已结束交易，零收益计未命中 |
| OOS_T_STAT | t 严格 **> 2.0** | 后段日净收益均值 / 保守 HAC 标准误；原假设均值不大于零 |

所有比较使用未舍入值；等于边界不通过。缺失、非有限、退化方差不视为无穷大收益证据；旧报告缺失指标为尚未验证。额外最低研究样本为 **90 个完整 UTC 日、30 笔后段交易**，这是可估计性下限，不是独立样本充分性证明；既有实盘独立区块/统计功效要求继续有效。

以日末账户净值 E 定义 r[d] = E[d] / E[d-1] - 1，包含空仓日，现金基准为 0，不使用逐笔收益乘交易次数来年化。曲线中每个盯市点包含估计平仓费用与已累计资金成本。只采相邻、完整 UTC 日；首尾不足一日不插值、不补成日样本，相关损失仍进入逐 K 线最大回撤与总收益。

设 n 为日样本数，均值 μ，中心化收益 x[d]，样本方差 s²：

```text
L = min(n - 1, floor(4 * (n / 100)^(2 / 9)))
γ[k] = Σ(d=k+1..n) x[d] x[d-k] / n
V_NW = γ[0] + 2 Σ(k=1..L) (1 - k/(L+1)) γ[k]
V_gate = max(s², V_NW)
Sharpe_gate = μ / sqrt(V_gate) * sqrt(365)
t_gate = μ / sqrt(V_gate / n)
```

这是 Newey–West/Bartlett 形式的长期方差估计，并额外设样本方差下限，避免负相关帮助抬高准入分数；`sharpe_iid` 同时保存在 JSON 供对照。门禁夏普是保守 HAC 评分，不冒充有限期限精确年化夏普，t 是渐近 HAC 均值统计量，不冒充独立同分布 Student t 检验。序列相关会影响夏普年化及统计精度，参见 [Lo，The Statistics of Sharpe Ratios](https://alo.mit.edu/publications/page/18/)。

因此本轮约 101–105 日验证下，t > 2 实际比夏普 > 1.5 更严格；二者来自同一收益序列，不是两份相互独立的盈利证据。

## 候选假设与执行模型

| 候选 | 多头信号（空头镜像） | 可证伪假设 |
| --- | --- | --- |
| pullback / 趋势回踩再入 | ADX≥20，EMA20>EMA50；前收盘≤前 EMA20，当前收盘>当前 EMA20，RSI14 在 45–65 | 趋势内回踩后的恢复，可能减少追涨入场成本 |
| volume_breakout / 放量通道突破 | 收盘突破此前 20 根最高价，量>此前 20 根均量×1.5，ADX≥20，EMA 同向 | 有量确认的突破，可能减少假突破 |
| momentum / 波动过滤动量 | 20 根收盘变化>2 ATR14，EMA20>EMA50，EMA50 斜率为正，ADX≥20 | 超过日常波动的同向动量，可能具有延续性 |

空头回踩 RSI 使用 35–55。通道/均量不包含当前 K 线，前线值只来自历史前缀；收盘信号只能在其可用后的下一开盘成交。时间序列动量研究可作为候选假设来源，但原论文的市场、期限及仓位并不等同于本程序，本轮不是论文复现，更不是加密短周期获利证明。[Moskowitz、Ooi、Pedersen，Time Series Momentum](https://www.aqr.com/Insights/Research/Journal-Article/Time-Series-Momentum)

固定参数：EMA20/50、通道20、ADX20、止损2 ATR、止盈1.5R、最长持仓24根、初始账户10,000、每笔风险1%、无杠杆、合约双向。基础成本单边手续费5bp、单边滑点5bp、每8小时资金成本1bp；压力组分别10/10/2bp。资金费用为保守双向收费模型，不伪称已重放真实逐期资金费率。没有盘口深度、成交量参与率和实盘撮合保证，因此仍需既有成本模型认证。

同根止盈止损冲突按止损先发生；跳空止损按不利开盘价处理；剩余仓位在分段结束时平仓。报告保留信号时刻、实际入场/退出记账时刻、指标快照、OHLC、成本、曲线及来源修订号。

## 反过拟合与证据边界

本批次包含之前已有7次研究，共按31次计入试验预算；24个报告都保存，压力试验也计数。候选须基础与双倍成本都通过，最终 shortlist 为空。多次尝试只展示赢家会造成选择偏差，所以不删除失败事实，不把普通 t>2 解释成经过多重检验的显著性。[Bailey、López de Prado，The Deflated Sharpe Ratio](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)

研究回放使用 `HISTORICAL_CLOSE`：明确假设当时收盘数据已可用，而实际使用当前保存的历史修订；这不是交易时真实接收流。70/30后段可见，不是一次性消费的封存 holdout。本批次没有产出嵌套 walk-forward、DSR/PBO 或足够独立样本的实盘认证产物。四项仅为必要筛选门槛，原19项认证条件保留，新增4项后共23项，TESTNET/LIVE 不能因为研究 PASS 被开启。

数据库迁移0026让证书写入必须具备23项；新增触发器按实际数值重新检查四项及样本量，不能仅写 PASS。旧19项证书保留，但不能授权新 TESTNET 演练。本轮无存量执行证书、无实际下单；LIVE 总开关仍关闭。
