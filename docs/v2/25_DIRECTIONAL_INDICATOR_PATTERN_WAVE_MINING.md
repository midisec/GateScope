## 结论

本轮不含资金费率对冲、跨市场套利、马丁和网格补仓。两批共 **4,176 个开发组合、56 个冻结后段验证方案，0 个满足全部四项门槛，0 个可部署**。这是本轮搜索范围的负结果，不是证明市场上不存在达标策略；不能把较高命中率或开发期盈利当成部署依据。

## 可执行的研究规则定义

共同基础指标：EMA20/200、RSI14、ADX14、ATR14、布林20/2；额外RSI2、MACD12/26/9。指标逐根更新，当前收盘生成信号、次根开盘才成交。

| 类别 | 规则 | 入场要点 |
| --- | --- | --- |
| 指标 | RSI2趋势回踩 | 价格在EMA200上，RSI2从10下方回升穿越10；空头对称使用90。 |
| 指标 | MACD动量 | 柱线由负转正且MACD在零轴上；空头对称。 |
| 指标 | 布林回归 | 前收盘在下轨外，本收盘回到下轨内且RSI<45；空头对应上轨、RSI>55。 |
| 指标 | 收缩突破 | 前根带宽处于过去120根低四分位，本根带宽扩大、收盘越过前20根通道，量>前均量1.2倍。 |
| 形态 | 趋势回踩吞没 | 前阴后阳、实体吞没、低点在EMA20下而收盘回到线上、RSI<60；空头对称。 |
| 形态 | 双底/双顶 | 三个确认枢轴，底部差≤0.75ATR、高度≥2ATR、跨度6—120根，收盘突破颈线0.1ATR。 |
| 形态 | 头肩反转 | 五个确认枢轴，中间头部更深≥0.75ATR、肩差≤1ATR，收盘突破按已知枢轴线性延伸的颈线。 |
| 形态 | 收敛三角 | 六个确认交替枢轴，上沿不升、下沿不降、拟合偏差<0.6ATR、宽度收缩后收盘突破0.1ATR。 |
| 形态 | 旗形延续 | 已知16根旗杆振幅>5ATR，随后8根整理宽度<杆长0.618、回撤受限，再收盘突破整理区。 |
| 波浪 | 三浪候选 | 仅已知0、1、2三个枢轴，浪1≥3ATR、浪2回撤0.382—0.786且不破0；投影2＋1.618×浪1。 |
| 波浪 | 五浪候选 | 仅已知0—4，浪2不破0，浪3过1，浪4不重叠浪1、回撤0.236—0.618；投影4＋min(浪1,0.618×浪3)，必须超过3。 |
| 波浪 | ABC修正反转 | 四个确认枢轴，B/A回撤0.382—0.886、C/A长度0.618—1.618，C过A；反转目标为B点。 |

枢轴取严格左右各3根分形，必须等待右侧3根全部收盘。一个K线若同时满足高低分形，不知道高低发生顺序则放弃。已生成信号保留原始锚点和确认时间，不因未来枢轴延伸而改写；同结构只发一次信号。完成三浪、五浪并不是入场时已知事实，不能反过来标记入场成功。

这些规则是可检验假设而非盈利定理。自动化图形检验的研究背景见 [Lo/Mamaysky/Wang 原论文](https://www.nber.org/papers/w7613)；波浪候选的回撤与失效位背景见 [CMT 的波浪交易教学](https://cmtassociation.org/technically_speaking/technically-speaking-july-2006/)。本项目不是这些研究的复现，也不把其结论当作加密资产利润证明。

第二批的环境过滤预先固定为：ADX<20；ADX≥25且EMA20/200同向；EMA80/800同向；ATR/收盘不高于之前240根中位数。长均线只是较慢的同周期趋势代理，不冒充严格聚合后的高周期EMA。

## 风险、成本与统计边界

- 单仓位、单笔账户风险0.5%、名义敞口≤账户净值。不靠加杠杆、摊平亏损或删亏损提高指标。
- 结构规则使用当时失效位外0.25ATR止损；无结构时QUICK用2ATR，其余3ATR。开盘后距离不在0.25—6ATR或目标不利则拒绝入场，不能用已达到的旧投影目标制造收益。
- QUICK：0.8R、最多24根；SWING：1.4R、最多72根；MEASURED：当时结构目标、最多72根；无结构目标时退回1.4R。
- 基础单边手续费5bp＋不利滑点5bp，压力全部翻倍。用历史实际有符号资金费；缺结算标记价时用该周期合约开盘代理。对入场/退出所在K线的结算先后不确定，只计可能支出，不领取不确定收入。
- 止损止盈同根触发按止损先到；不利开盘跳空按实际开盘。逐笔退出时间为K线结束记账，并标记盘中OHLC或收盘退出，不伪造精确tick时间。
- 净值按周期收盘盯市，图表按日显示；日夏普与t使用完整UTC日，含空仓日，现金基准0，保守HAC方差。两者共享均值/方差，不是两个独立显著性证据。
- 流动存续币种是便利样本，存在生存者偏差；未复现历史数据到达时间、逐笔流动性、实际账户费率、ADL、故障与退市。当前结果不能授权实盘。
