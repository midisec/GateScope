## 规则矩阵

| 类别 | 类型 | 主要可检查规则 / 本次调整 |
| --- | --- | --- |
| 反转 | 双顶、双底 | 已确认峰谷、峰间颈线、价格和时间交替；第二端尚未确认时维持形成中；前置趋势不足显示警示，不删除几何候选 |
| 反转 | 三顶、三底 | 三个主峰谷、两个中间颈点；按两点颈线投影确认，锚点必须真实且顺序正确 |
| 反转 | 头肩顶、倒头肩 | 头部突出于双肩；颈线连接两真实颈点；前置趋势标记与几何匹配分开 |
| 持续 / 反转 | 杯柄、反转杯柄 | 左沿改用实际局部收盘极值，不用平均值代理；主体按固定锚点比较圆弧与 V 模型；柄深不超过主体一半；严格时间顺序 |
| 持续 | 看涨旗形、看跌旗形 | 至少 3 ATR 旗杆；回撤范围限制；边界平行；斜率容差改用 ATR / 整理跨度；不再未经测量宣称“缩量” |
| 持续 | 看涨三角旗、看跌三角旗 | 同样检验旗杆、整理宽度；上边下行、下边上行并收敛；至少两个高点和两个低点 |
| 整理 | 上升、下降、对称三角形 | 水平/倾斜边按 ATR 全跨度位移区分，收敛且未交叉；再核验类别与线的斜率相符 |
| 整理 | 矩形 | 两边水平、宽度稳定、多次触点；突破前不指定唯一方向 |
| 趋势 | 上升楔形、下降楔形 | 两边同向且收敛；上下斜率关系正确；拟合残差不过大；不能将交叉边界排序后伪装成正确 |
| 趋势 | 上升通道、下降通道 | 同向近似平行、宽度稳定；保留嵌套通道，不按结束时间强行合并 |
| 波浪 | 艾略特上升五浪、下降五浪 | 二浪不越起点、四浪不重叠一浪、第三浪不能最短；当前实现是标准非斜三角且非截短五浪子集 |
| 波浪 | ABC 下跌修正完成、上涨修正完成 | 简化锯齿 ABC 顺序、A 浪振幅、C 回到 A 附近；比例偏离不等于硬性无效 |
| 波浪 | 上升五浪+ABC、下降五浪+ABC | 严格推动浪后接修正；C 接近 A 的容差由固定 2% 改为 0.25 ATR；禁止同根 K 线高低点假定先后 |
| 新增 | 阻力突破回踩、支撑跌破反抽 | 突破前 32 根确定水平位，至少两次相隔四根的测试；先两根收盘越过 0.15 ATR，之后才可回测；再等待反弹确认；24 根到期 |

所有类型都检查锚点时间/价格，保留可解释的拒绝原因。未完成波浪不人为补未来枢轴。
杯体原理线改为通过真实左沿、底/顶、右沿的两段圆弧参考线；不再将 U 形画成 V。Web 与 TG 使用同一二次曲线公式，逐真实 K 线时间采样；曲线不是新增价格枢轴。
波浪比例仅用于匹配/条件目标；原先二浪 15–88%、四浪 12–75%、ABC 固定比例区间不再充当新版的硬准入门槛。
没有验证低一级 5-3 子浪，所以界面明确说“波浪候选”，不称唯一有效数浪。

杯体底部停留少并不单独导致删除：只有 V 模型误差显著小于圆弧、且归一化 V 均方误差低于 0.04，才拒绝明显 V 形。非典型/噪声圆弧保留并提示。
这些 ATR、跨度与模型比较阈值是可复现的工程定义，不是来自数学定理的盈利保证。

## 三个不同量

1. 几何匹配：规则内的相似程度分数；不是成功概率。未完成结构可以没有几何评分。
2. 形成概率：同类已结束的非重叠“形成中”候选中，曾到达 FORMED 的比例。
3. 突破确认概率：同一已结束样本中，最终达到 CONFIRMED 的比例。

例如形成后失效，在第二项是成功、第三项是失败。先前只有第三项，不能再将它笼统称为“形成概率”。
两个分母均使用已结束队列：CONFIRMED / INVALIDATED / EXPIRED；仍待定与 CENSORED 排除。
统计故意等待候选结局才纳入形成率，避免在缺少形成时间投影时偷看未来形成标记；页面不要将它描述为全部存活候选的即时无偏估计。

每个概率展示样本数和 95% Wilson 区间，按 28 类型 × 2 阶段 × 5 分组 × 2 结局 = 560 比较校正。
不足 20 个样本不给预测百分比/区间。区间宽度是历史估计的不确定性，不是额外伪造的“高可信百分数”。
概率结果携带 `precision`（不足 / 宽 / 中等 / 窄），阈值分别是校正区间宽度大于 0.4、0.2–0.4、不超过 0.2；不用于隐藏形态或放行交易。

实测优先于同候选回放；跨来源去重、排除重叠；仅使用当前候选之外、一年内且结局严格早于判断时刻的样本。
首次判断的概率与预测点位存入不可变时间线；Web 实时参考与档案的当时估计分别显示，TG 原始图使用当时估计。
时间相关、完整结局筛选偏差、制度变化和小样本仍可能使估计失真；95% 不是下一次一定落在区间内的承诺。

## 版本与运行

- 0031 只扩展允许的模型版本，不修改历史事实。
- 旧模型活跃候选以 MODEL_CHANGED / CENSORED 结束，不伪造失败；旧版档案可继续查询。
- 后台按自选订阅自动生成新版实时状态与一年回放；只使用新版样本估计新版概率。

- Legacy 通知/策略引擎的默认输出仍由黄金测试保护；新版研究形态不自动接入执行。

## 参考与适用边界

形态突破、确认过滤、回测与失败的定义参考 [Fidelity / Charles Kirkpatrick 的形态课程](https://www.fidelity.com/bin-public/060_www_fidelity_com/documents/learning-center/Idenitfying-Chart-Patterns.pdf)。它也指出回测不一定发生，不应假定新增回测形态天然更好。
推动浪的硬性规则与指南区别参考 [Elliott Wave International：Impulse](https://www.elliottwave.com/waveopedia/impulse/)；其定义不意味着简单 OHLC 检测已验证全部子浪。
量化识别与统计检验的研究出发点参考 [Lo、Mamaysky、Wang（2000）](https://www.nber.org/papers/w7613)；不将其他市场/时期的研究结论移植为本产品的盈利证明。
