# 平台闭环、历史对比与存储优化

已发布版本：MCP `1.4.0`；迁移 `0047` 至 `0051`。本文末尾单独记录实际验收范围，不将代码实现与生产实测混为一谈。

## 历史信息保留原则

保留形态数量、首次出现/形成/确认/失效时间、原始预测、关键价格、模型版本、抽样及重叠标识、失败与删失原因、各期限收益/MFE/MAE。既有失败案例不删除，原始 K 线版本不缩减，未成功的预测不能被后来更漂亮的图覆盖。

`0047` 为事件增加可选压缩体 `event_blob`。`event_json` 中保留检索投影；完整原记录使用有长度上限、SHA-256 校验的无损 zlib 保存。列表查询不解压，详情、策略、TG、MCP 与开单依据按需还原。旧 JSON 行与新格式混合可读；压缩发生在存储边界，不改变检测规则、事件 ID 或统计口径。

阶段表中的重复预测详情可以替换为对比摘要：预测时间、目标/理论目标及区间、来源与样本数量、状态、确认价格，以及指向同一候选的不可变原始事件序号和摘要哈希。只有在完整预测可以从该事件精确还原时，才允许替换旧记录。完整文字与几何仍从事件证据读取。

### 历史迁移操作

```sh
.venv/bin/python scripts/compact_structure_storage.py --mode events --max-rows 500 --seconds 20
.venv/bin/python scripts/compact_structure_storage.py --mode stages --max-rows 500 --seconds 20
# 核对 dry-run 后再明确执行；该脚本不会删除样本或重建大表。
.venv/bin/python scripts/compact_structure_storage.py --apply --mode events --max-rows 500 --seconds 20
.venv/bin/python scripts/compact_structure_storage.py --apply --mode stages --max-rows 500 --seconds 20
```

每批最多 32 行，采用键集进度、单批事务、1 秒锁等待和 5 秒语句上限；每批重新检查至少 2GiB 文件系统余量。旧记录以实际 PostgreSQL TOAST 大小与新表示大小比较，不足 5% 收益则跳过。每次持久化后再还原校验，出错回滚该批，成功批可以续跑。进度及批次摘要由维护账号独占，业务角色无权调用重编码函数。

**存储缩小不等于 `df` 立即下降。** 普通 PostgreSQL 更新会产生待清理旧版本，autovacuum 后的空间可供复用；本脚本不执行 `VACUUM FULL`，不禁用不可变触发器，不大规模复制/重建索引。不能拿 JSON 文本压缩比当整个数据库回收比例。暂不自动开启大规模历史重写。

`0047` 显式降级会逐批还原所有压缩体及预测引用，可能产生大量 WAL、持锁并需要额外空间；生产优先前向修复，不能用旧版不支持压缩的代码覆盖运行目录。其他新增账本/研究迁移禁止直接丢弃已有生产事实。

## 模拟交易闭环

- TG 通过已验证绑定读取新 MCP/Web 共用账户；旧信号交易保持独立标识。订单、持仓、余额与原图使用只读交互，查询重试重新读取当前账本，不复播旧余额。
- Web 开仓先预览张数/币数/名义额、预算、预计可成交量、费用及止损处的预计损失，再明确提交；真实提交重新验证行情和资金，预览不是成交承诺。超时重试保持原幂等键。
- 开单可携带 `decision_context`。服务端冻结当时实际已入库、已收盘 K 线及其版本、EMA9/21、RSI14、指定形态事件；单一依据包有严格大小上限。客户端模型名、理由和 Coinglass 声明明确标记为客户端提供，不能冒充服务器验证。
- 不附依据的旧单/手工单标记 `UNASSOCIATED`；不会事后补造分析。原图只读取开单快照，新增 Web 图像接口及 MCP `paper_order_chart` 返回原始 PNG。
- 账户记录增加所有者/筛选条件绑定的游标及插入时间上界；翻页不清空余额。上界不冻结可变的当前持仓状态，当前余额仍持续更新。
- 订单详情可继续读取超过 100 条的成交/事件。Web：`/api/v2/paper/orders/{id}/fills`、`/events`；MCP：`paper_order_history`。新工具仍要求原有显式 `paper:read` 授权，不扩大历史只读连接权限。

模拟成交仍使用当前公开盘口的保守参与率、合约规格、手续费和滑点；本次未启用实盘。止盈止损价不是保证成交价，断网、报价过期、部分成交和未观测到的瞬时穿价仍需如实呈现。

## 年度指标与共享资金回测

普通指标及组合指标长历史走分片路径，最多 550000 根；原 5000 根以内兼容旧引擎。每块 512 行，冻结输入及输出用压缩、校验和、所有者隔离的研究块保存，浏览器和 MCP 按页读取，避免在报告 JSON 中重复塞入全年 OHLC/指标/资金曲线。

读取采用“下一有效开盘时间 + 固定周期窗口”，不对每一页反复排序剩余全年数据。界面展示请求范围、实际可用范围、内部缺口与截断标识。进程中断后复用冻结输入确定性重算；这不等于从每个指标中间状态续算。包含旧式形态扫描器的组合引擎仍有显式 5000 根/计算预算限制，不静默宣称已支持全年。

指标特征的历史窗口采用有上限的滚动前缀，回撤恢复扫描缓存原峰值，避免每根 K 线跨分片反复解压。同一 6000 根 cProfile 对照中，分片特征计算从 39.45 秒降至 2.20 秒，Bar 重建次数从 413225 降至 6000，输出 SHA-256 与优化前及普通列表完全一致。此数值是特定合成负载的对照，不是生产全年任务的耗时承诺。

共享资金组合回测是独立研究功能：选择同一用户已有的完整、不可变结构研究来源，冻结来源清单、共同时间区间和分配规则。按历史信号/成交事件时间分配资金，限制并发持仓、同币种叠仓和总敞口，入场扣费及占用本金、退出释放；保留资金拒绝、重复信号、未成交、规则排除及观察区间末的未决案例。

组合净值使用当时可知的冻结价格，不插值补齐缺口。缺失估值时相应账户绩效不可用；未平仓不假装已经实现盈亏。历史数量为连续名义数量，不伪装已取得交易所历史盘口、历史合约精度或真实排队位置。独立形态统计保留原口径，组合绩效不回写原研究案例，不重新引入已取消的部署绩效门槛。

仓位预算计入止损价差、配置的止损滑点、进出场费用与配置持仓期内资金成本。历史跳空、额外延迟或超期持仓仍可能超出预算。实际退出时间与资金可用时间分别保留；严格记录模式必须等到整个相关 K 线前缀实际可知后才能释放平仓资金，迟到的旧收盘价不能更新报价新鲜度。已完成来源禁止追加新的输入、事件和案例，新分片以复合外键校验账户归属。

## 概率可靠性

在已有过去样本校准上增加全年/近期 30 天对照、固定概率分桶、原始预测均值、同预测样本群实际确认率、Brier 与区间。形成频率、确认概率和盈利概率分开；两时间窗口相互重叠，只作为描述对照，不声称是独立样本显著性检验。

新观察和新回放的阶段可保存短市场环境标签，特征仅使用该时点之前已收盘前缀；旧数据未记录的标签保持空值，不事后伪造。当前环境匹配样本不足时回退总体参照；对比信息不会自动替换原始发布置信度，也不承诺提高胜率。

近期与全年都列出抽样候选、未决及删失数量；截至观察点还未知的终态不会泄漏进成功率。环境字段迁移使用 `NOT VALID` 检查约束，仍约束新写入，但部署时不扫描约 5.8GB 旧阶段表。

修复通道同一组完整真实锚点在不同扫描窗口中因浮点舍入选择不同起点的问题：只规范化同锚点重复边界的显示窗口，保留最长有效窗口。独立候选计数、几何准入和既有归档不变，不回写旧预测。

## 业务健康与容量

新 PAPER 撮合、旧信号交易和影子研究分为独立循环及连接池，研究慢查询不再串行阻塞新仓位保护。各自记录最后成功业务时间、降级原因与心跳。健康检查额外检查保护巡检年龄；上游不可用、业务降级和磁盘压力不会导致无条件重启 API。

模拟账户页面显示撮合业务健康。磁盘 85% 起输出容量告警。异机备份位置需要用户确认；转存、完整性校验、隔离恢复演练完成之前，不能删除本机唯一副本或宣称备份可恢复。
