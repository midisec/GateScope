# Coinglass 独立调度、渐进数据与可观测排队

日期：2026-09-13；迁移：`0044_coinglass_queue_progress`。接续 [限流恢复](43_COINGLASS_RATE_LIMIT_RECOVERY.md)。

## 原因

0043 已修复过期 RATE_LIMITED 和 MCP 补采，但尚有首屏延迟：Coinglass 单任务在专用 executor 运行，下一任务提交却在 Gate 同步 `sync.run_cycle` 之后。Gate 多订阅串行同步慢或出错时，Coinglass 任务之间也被拖慢。额外的批次冷却约 54.5 秒与逐 HTTP 共享限速叠加，产生不必要的空等。

旧 QUEUED 根据 GET 是否申请补采推导，未检查真实 lease，无法区分已经采集、等待调度、上游冷却。整批完成才写缓存，使持仓量已经成功时仍对外显示全部为空。另外，首次排队与最近访问热度共用两小时资格，过久未调度的请求可能掉队。

现场只读检查时 SOL 4h 已在 19:21:45 取得数据、SOL 1d 于 19:22:44 取得数据；这是延迟和状态表达问题，不是该时刻上游持续不可达，不能用旧文字描述替代实际查询结果。

## 变更

- 专用、可停止的 Coinglass 循环在主行情循环前启动；每轮最多一个连接测试和一个图表任务，空队列/异常等待两秒。有工作继续处理，HTTP 仍使用共享密钥限速器和持久 Retry-After，不增加请求并发、不绕过上游额度。
- 真实取得一组指标即可发布完整维度的 PARTIAL 快照；其余指标 DEFERRED 或明确单位未验证。同一 lease 继续采集，publish 不改 due、不清排队、不提前结束任务。每组数据保留实际采集时间、到期时间和 available_at。
- pending_since 持久表达请求，重复查询不重置排队时间，不再因超过两小时而丢弃首次任务。完成一次采集后清理 pending，已访问周期的后续预热仍遵循两小时热度和默认自选周期。公平顺序不以用户重复轮询刷优先级。
- 配置版本变化重置排队/采集身份；过期 lease 和旧密钥任务不能发布进度或覆盖新缓存。维度/单位不一致不复用。
- `status` 表示数据质量；`refresh_state` 独立表达 QUEUED / COLLECTING / COOLDOWN / SCHEDULED / IDLE / NOT_REQUESTED。返回真实 queued_at、queue_age_seconds、collection_started_at、next_eligible_at、next_poll_after_seconds、cache_available 和 last_success_at；最早可开始时间不等于预计完成时间。
- `coinglass_get_snapshot` 增加 `wait_seconds`（0–15，默认15）。已有可用或可参考的历史数据立即返回；空缓存可短暂等待本用户的本地缓存，每秒最多一次、只首读申请入队、后续读不再次入队。首读计入预算，预算耗尽不启动下一次读取。15秒是本地等待预算，不承诺整个HTTPS端到端耗时；连接池等待、查询完成与传输可能额外耗时。缓存get使用事务级查询超时2秒/锁等待1秒。不会在 MCP 中解密密钥或请求上游。COOLDOWN、不可用配置、超出等待预算的未来调度立即返回真实状态。
- MCP 的 availability 逐指标列出 ready/stale/unavailable 及点数，不把 PARTIAL 或队列状态误解为全部没有数据；未验证单位、错误周期、未来可用时间不计入可用指标。STALE 只作历史参考，不作为新的实时交易证据。
- Web 分开展示刷新进度和就绪 X/5、历史参考 Y/5，已有曲线保持可见。排队/采集按后台建议检查（通常5/3秒，客户端限2–30秒），上游冷却仍严格遵守 retry_at，网络/接口错误退回30秒检查。完整 MCP Web 预览仍为手动快照，不高频轮询整个行情分析接口。
- 明确 IDLE/NOT_REQUESTED 且 next_poll_after_seconds=0 时停止自动轮询，仍保留手动、网络恢复和页面可见时检查。
- 正常刷新按最早有效系列到期前5秒调度，不再使用长于缓存TTL的固定刷新周期；形成研判逐项校验系列期限、采集时间与周期，过期系列不借最后一项的时间继续参与分析。
- 采集被429中断的缺项重试不再等待正常10分钟TTL：采用本凭据身份30/60/120/240/300秒退避，与持久Retry-After取较长者；成功后重置，仅观察既有冷却不增加失败次数。退避记忆在有界客户端LRU中，重启仍保留的是数据库实际限流截止。当前重试仍可能重取同批已成功指标，不宣称已实现缺项专用请求。
- 资金费率单位 UNKNOWN 的独立问题未被此修复掩盖，不能把已恢复四项指标宣称为五项全部可用。
