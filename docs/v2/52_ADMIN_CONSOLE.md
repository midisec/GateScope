# 独立工作区管理后台

日期：2026-09-16。

## 入口与范围

管理员用户名菜单 → **管理后台**，或直接访问 `/admin/overview`。
管理后台有独立布局，不挂载行情、交易页面及其后台轮询。
只有已完成当前登录安全要求的 `OWNER` 可以访问；普通用户不显示入口，直接调用接口也被拒绝。

本轮是**当前工作区管理**，不是跨工作区超级管理员。不会因某个工作区的 OWNER 身份开放其他工作区的用户资料，也不会修改 owner 的密码或 MFA 配置。暂停的体验账号创建任务没有恢复。

| 路由 | 功能 |
| --- | --- |
| `/admin/overview` | 成员数量、有效会话、近 7 天密码登录结果、业务资源数量 |
| `/admin/users` | 服务端搜索／角色和状态筛选／分页、用户详情、创建、角色变更、停用／恢复、注销其他成员的 Web 会话 |
| `/admin/resources` | 当前工作区业务计数、共享数据库大小及主要表占用、应用主机磁盘容量 |
| `/admin/audit` | 身份与成员操作记录，按动作及结果筛选、分页 |

页面支持 390px 手机宽度；宽表在表内横向滚动，弹窗支持关闭和取消。提交显示进行中状态、禁止重复执行。密码过期提供加密的再次确认；确认成功后不自动重放原写操作。版本冲突提示刷新重编辑，网络超时不自动重试写请求。

## 身份与权限

- 创建成员使用 `tenant:{tenant_id}:user_create` 的 RSA-OAEP/AES-GCM 加密提交。公网不接受明文密码 JSON；密码不进入响应、审计或统计。
- 新成员默认必须绑定验证器。后台不提供代看密码、关闭别人的 MFA、批量复制密钥或修改全局账号状态。
- `VIEWER / RESEARCHER / OPERATOR / OWNER` 是工作区角色。停用操作修改的是当前工作区成员资格，不删除用户和历史业务数据。
- 创建、修改和会话注销需要近期密码认证；所有写操作需要 CSRF 校验。成员修改还需要 `If-Match`，保留现有乐观锁。
- 成员修改按工作区序列化，在事务中重新检查管理员和会话资格。两个管理员并发自降级只能成功一个，保留最后一个有效 OWNER。
- 停用会撤销该工作区的 Web 会话。MCP／TG 交互每次重新验证成员资格。通知发送前也重新检查接收者，已停用成员的排队消息终止，不会因重新启用而补发旧消息。
- “注销会话”只注销 Web 会话，不代表永久撤销 MCP token、OAuth grant 或 TG 绑定。重新启用成员后，未过期的既有外部授权可能恢复可用。
- 通知资格检查不改变交易保护、减仓和平仓逻辑。已发出到 Telegram 的在途请求不能追回；数据库检查与外部发送不是跨系统原子事务。

## 统计口径与资源成本

成员与业务数据有数据库 RLS，并显式限制 `tenant_id`。目前业务计数包括自选列表／标的、保存的图表布局、指标模板、告警策略及模拟账户；不会把管理员自己可见的订单或回测误标为全工作区总数。

“有效会话”包含尚未过期且未撤销的密码阶段会话，包括等待 MFA 的会话，不表示实时在线人数。登录趋势按 UTC 日期统计已记录的密码登录事件，不冒称 MFA 最终成功率。表格时间按浏览器本地时区展示。

共享存储来自 PostgreSQL catalog：显示全库大小、选定业务表及继承分片的大小（含索引）和估算行数；不扫描数百万根 K 线做精确 COUNT。估算行数可能滞后。外置 Timescale 压缩存储未全部归属到父表，页面明确提示，不能将表格行相加当成完整数据库大小，更不能作为每用户计费数据。

应用主机文件系统的容量不是数据库专属盘声明；系统预留块会导致总量不等于已用与普通用户可用之和。数据库与应用分机部署时，两者更不可混同。统计接口失败显示不可用，不补成 0。

每条统计 SQL 超时 5 秒，锁等待 1 秒；列表最多 100 条，物理目录最多 5,000 个 relation。管理读请求有独立限流，接口不缓存到浏览器。无新增行情副本、后台采集任务或长期统计大表。

## 代码与发布

- 前端：`web/src/AdminConsole.tsx`、`adminConsoleModel.ts`、`adminConsole.css`，应用根路由在普通工作台之前选择独立后台。
- API：`apps/api/admin_console.py`，路径 `/api/v2/admin/{overview,users,resources,audit}`；注销会话为 `POST /api/v2/admin/users/{id}/sessions:revoke`。
- 创建／编辑复用 `/api/v2/users`、`/api/v2/memberships/{id}`；OpenAPI 生成器标记角色、工作区、近期认证和 CSRF。
- 查询与统计：`src/gatescope/application/admin_console.py`。
- 迁移 `0052_admin_membership_grants` 仅给身份角色 `gatescope_auth` 增加 memberships 的 INSERT/UPDATE，既有 FORCE RLS 不变；没有 DELETE、BYPASSRLS 或跨租户权限。
- 只需重启 API 与通知 worker。行情、PAPER、策略、MCP 服务无需停止。前端先放完整哈希资源，再原子替换入口，保留已打开页面所需旧资源。
- 回退先恢复旧前端入口和对应 Python 源文件，再重启这两个服务。该授权迁移可单独回退，但应先关闭新成员管理功能；不删除新建用户或历史审计。
