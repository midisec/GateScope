# 2026-09-11 部署复验与交互性能优化

正式入口：**https://43.108.44.74/markets/chart**。

本轮不是只检查 HTTP 200：在新机通过真实 Chromium 登录原账号、完成 MFA，访问正式接口并操作桌面/手机页面；另用隔离数据库和浏览器 fixtures 验证增删改、失败重试和并发切换，避免污染真实策略和订单。

## 本机停用

旧机 `43.155.154.25` 的 GateScope API、行情、策略、PAPER、通知、MCP、两个 executor、健康检查 timer 已停止并禁用。PostgreSQL 实际 cluster 已停止。按本轮要求，旧 Nginx 与旧 Certbot timer 也已停止并禁用，所以旧地址**不再跳转或提供页面**，请直接使用新地址。

旧代码、数据库和私有迁移备份均保留；没有停止与本项目无关的监控或管理进程。

## 查出的具体问题与修改

1. **续期任务冲突**：迁移时手工 Certbot 演练与自动续期同时启动，自动任务因锁冲突留下失败状态。已真实重跑成功，并增加失败后 5 分钟重试、每小时至多 3 次的 systemd 规则；不再必须等六小时后的 timer 才重试。
2. **行情最新时间查询浪费**：原来每次轮询用 `MIN + MAX` 查询所有历史分区。一次 EXPLAIN 显示规划约 284 ms、执行约 49 ms。改成先查最近时间范围的 MAX，并用绑定的具体时间让 TimescaleDB 在规划阶段排除旧分区。没有近期数据时回退完整 MAX，保留停更/离线币种的最后缓存，不猜测时间或返回假行情。
3. **短历史重复全量下载**：不足 1500 根的市场不再每五秒重复请求全量。正常采用末尾 8 根增量，每分钟做完整校验；跨越增量窗口的缺口仍触发全量修复。
4. **图表和指标刷新抖动**：不变的已收盘 K 线保留数组引用；实时尾根通过 `series.update` 更新，历史修订/窗口变化仍完整替换。指标 series 不再随每次轮询被删除重建；后台计算期间保留同币种、同周期、同配置的已有指标，跨币种/周期立即隔离，禁止显示旧标的指标。
5. **菜单关闭与手机空间**：用户菜单支持 Esc、外部点击和返回焦点；只有一个工作区时自动选中。手机自选区压缩重复内容，指标/统计/保存改为同一工具行，保留触控按钮尺寸、搜索与移除入口。
6. **无效传输与轮询**：内容哈希静态资源启用 gzip 与一年 immutable 缓存，旧资源仍保留给已打开页面。认证 JSON 不缓存、不增加压缩；首页 HTML 仍 no-store。通知角标每次只取一项和服务端总数，隐藏页面暂停、慢请求不重叠、离开页面取消。

上述修改没有改变指标定义、历史预测档案、回测收益口径或交易门禁。

## 性能对比

| 测量项 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 同机最新 K 线时间查询，5 次中位数 | 200.10 ms | 1.71 ms |
| 1440 px 浏览器，8 周期切换响应中位数 | 504.5 ms | 376.5 ms |
| 390 px 浏览器，8 周期切换响应中位数 | 416.0 ms | 242.0 ms |
| 主 JS 实际传输体积 | 622,064 bytes | 201,808 bytes |
| 主 CSS 实际传输体积 | 72,755 bytes | 16,838 bytes |

最新时间查询的返回时间戳一致。周期耗时从点击开始到对应成功响应和图表容器就绪；测试 Chromium 运行在新机，不代表所有用户的互联网 RTT、手机硬件或首次绘制耗时。浏览器验收启用了写请求拦截，这会禁用浏览器 HTTP 缓存，因此未把 immutable 命中带来的收益计入对比。每组只有 8 个周期样本，不能当作大规模压测结果。

页面检查脚本还包含约 700 ms 的固定稳定等待，因此其 `elapsed_ms` 不作为“页面加载速度”指标宣传。

## 发布与边界

前端先复制内容哈希资源，再原子替换 index；新入口为 `index-Jg-ySIZ0.js` / `index-S7pHpvWd.css`。新机 `/root/gatescope-install/` 保存了本轮发布前的 HTML、API 路由代码和 Nginx 配置。后端只重启 API；业务数据未清空，未重复启用旧机 worker。

运行结束时新机可用物理内存约 **4.6 GiB**、系统盘约 **56 GiB** 可用，无 OOM。测试期间出现少量 swap 使用，不能把“有 swap”误判为内存耗尽，也不能承诺任何规模都不会遇到瓶颈。

本轮没有做真实下单、真实止盈止损或交易所断网故障注入；现有库没有交易所账户，LIVE 仍关闭。MCP 保持已有的只读/回环部署。统计认证生产器、实盘资格等未完成项仍以主 README 为准，不能据本轮验收宣称“全部实盘功能完成”或“策略必然获利”。

## 复验入口

在新机项目目录，以应用用户运行：

```bash
BROWSER_EXECUTABLE=/opt/gatescope-tools/chromium/chrome-linux64/chrome \
uv run --frozen --with playwright python scripts/smoke_live_browser.py --label recheck
```

默认只做读取/页面操作；`--external-tests` 会额外发一条真实测试通知并执行一次 Coinglass 检测，只有明确要重测外部通道时才使用。禁止把它加入频繁定时任务。
