## 1. 使用入口与保存

登录后进入 **行情 → 精选指标**，路由为 `/markets/chart`。搜索指标名称、OI、持仓量、资金费率或 VPVR；可按“全部 / Coinglass / 量价”筛选，多项勾选立即作用于当前图表。电脑与手机都保留多选，搜索和分类不会清掉已选项。

已选项可以单独移除或清空；关闭弹窗、点击“完成”仅关闭选择器。清空不会丢弃之前调整的 VPVR 显示参数。需要刷新页面后继续保留时，点击行情工具栏的 **保存**，将选择与参数写入当前用户的“默认工作台”布局；选择器本身不自动提交布局。

仅打开选择器不会请求 Coinglass。选择 Coinglass 指标或打开原数据口径/形态研判面板后才启用现有读取通道；只选择 VPVR 不需要 Coinglass 请求。未配置、排队、限流时仍可先勾选，但不会伪装成数据就绪。未配置时可进入 `/integrations/data-sources`；限流按绝对 `retry_at` 倒计时，等待期间不能重复手动刷新。

本次是五项原生系列、一项原生数据派生与一项本地估算，不是七个新的上游接口。OI 美元估值变化同时受价格与持仓变化影响，不能解释为净流入；实际爆仓不等于未来清算热力图。本次不自动调整形态置信度、原始预测、止盈止损或下单规则，也不据此承诺提高胜率。

## 3. Coinglass 维度、时间与缺口

沿用现有服务端精确匹配的交易所、交易对、市场/产品、报价与结算币契约，图表进一步检查 `instrument_id`、`timeframe`、`match.status=EXACT`、系列原生周期和已核实单位。不能把同名币种的其他合约、不同周期或未知单位直接绘入当前副图。Coinglass 官方资金费率历史接口也按交易所、交易对和周期区分请求，但官方文档不能代替本中转站返回字段的实际核实。[Coinglass 资金费率历史接口](https://docs.coinglass.com/reference/fr-ohlc-histroy)

- 图表点必须精确对应现有 K 线开盘时间，且图表 K 线已确认收盘；数据点 `close_time` 必须等于开盘时间加原生周期，`available_at` 不早于收盘、也不晚于当前时间。
- 重复时间点、非有限值、未知单位、未来数据与负数 OI/爆仓不参与绘制；资金费率可为负。缺失点不替换为零，不吸附到最近一根 K 线。
- OI 变化率必须有相邻有效 OI 与对应已收盘 K 线；第一点或中间缺口不制造变化率。折线按连续区段分别绘制，不跨缺失周期连接，也不向全局时间轴添加补造时间。
- 当前可用、历史缓存、暂无数据分开显示。优先采用明确的系列采集/过期时间，旧协议回退整包时间；无法核实新鲜度或原生数据滞后时作为历史参考，不因重新渲染重置时效。
- 排队与缓存是否可用是两个维度：后台正在排队不意味着已有合格缓存必须消失；反之，缓存有点数也不等于当前区间有新鲜、对齐的可用点。

同时修复异步新响应被旧页面时钟误标为历史缓存的问题：每次数据改变使用当时真实浏览器时间校验，常规时钟仍为 30 秒，倒计时为 1 秒，不因此新增上游请求。图表计算独立按数据变化/30 秒时段更新，未变的数值不重复灌入全部图表系列。

## 4. VPVR 的计算与边界

算法版本为 `visible-ohlcv-profile-1`，方法为 `UNIFORM_LINEAR_PRICE_OHLCV_ESTIMATE`。只遍历图表真实可见逻辑范围与已加载 K 线的交集；边缘部分可见的 K 线按整根纳入，仅触及边界而没有可见宽度的相邻 K 线不纳入。空视野、视野完全在加载范围外或无有效 K 线时，不回退计算所有历史。

有效 K 线要求有限且合理的 OHLC、正价格、非负成交量；显式 `is_final=false` 排除，缺少收盘标记的旧数据单独计数并在读数中提示。当前主图读取近期最多约 1500 根加独立实时 K 线；后台存有一年历史不等于 VPVR 已读取一年。拖动和缩放改变统计区间，图外未加载历史不补造，实时未收盘 K 线不贡献估算成交量。

每根 K 线的成交量按线性 `[low, high]` 区间与各价格桶的重叠比例均匀分配；平价 K 线归入其所在桶。横柱宽度表示相对成交量，不给未核实单位的 K 线成交量贴上 USD 标签，不伪装为逐笔成交、买卖盘 Delta、真实筹码持仓成本或净资金流。

POC 是成交量最大桶的中心；近似相等时确定性选择较低价桶。价值区从 POC 向两侧逐桶扩展，优先选择相邻成交量较大侧、相等时较低价侧，直到达到目标比例。默认目标 70%，实际纳入比例可能因整桶扩展高于 70%；VAH/VAL 是最终区间的上/下边界。全零成交量不生成 POC；全平价只保留真实单一价格桶，不虚构最小 tick。极小价格采用可表示的桶边界，必要时减少有效桶数并保留精度标识；非零极小读数使用科学计数法，避免显示成零。

实现使用缩放及补偿求和控制浮点误差；总量溢出或低于表示范围的分桶量保持不可用标识，绘图使用有限的相对比例。主图 primitive 逐次通过真实蜡烛价格轴转换每条桶边界，支持对数/反向价格轴与不同设备像素比；不添加图表时间点，不修改价格轴自动缩放。视野变化合并到动画帧计算，关闭/切换时取消待执行工作并解除订阅。

本实现不是 TradingView VRVP 算法的等价复刻。TradingView 官方文档描述了其自身的细周期选择与 tick 分层规则，而这里使用当前已加载周期 OHLCV 的均匀线性估算。[TradingView Visible Range Volume Profile](https://www.tradingview.com/support/solutions/43000703076-visible-range-volume-profile/) 绘制扩展采用 Lightweight Charts 的 series primitive 生命周期和画布接口；使用该图表库不代表取得 TradingView 原生指标数据。[Lightweight Charts Series Primitives](https://tradingview.github.io/lightweight-charts/docs/plugins/series-primitives)

## 5. 布局设置与实现位置

`chart_studies` 保存于原有版本化布局 `spec`，本次不新增数据库迁移或交易权限。缺失/不支持的版本回到默认；指标 ID 白名单、去重，最多六项 Coinglass。参数必须为有效整数，非法项单独回默认，不影响其余有效配置。

```json
{
  "version": 1,
  "coinglassMetrics": [],
  "vpvr": {
    "enabled": false,
    "rows": 48,
    "valueAreaPercent": 70,
    "widthPercent": 25
  }
}
```

VPVR 可选 24/48/96 层，价值区目标 50–95%，侧边宽度 10–40%。Coinglass 默认未选择，VPVR 默认关闭；换币种和周期沿用所选指标，但数据按当前合约/周期重新匹配，不显示上一标的结果。

启用精选指标时，主图与副图高度随所选面板数量扩展，不再被旧固定高度压缩。默认主副图伸展比例为 360:140；同一指标结构下保留用户拖动后的比例。导出 PNG 包含 VPVR 主图绘制层，画布内保留 `OHLCV estimate` / `VPVR EST.` 估算标记。
